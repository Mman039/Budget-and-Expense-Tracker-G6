
# Centsible

A mobile budget and expense tracker built with Expo and React Native.

## Run the app

```bash
npm install
npm start
```

Open it in Expo Go by scanning the terminal QR code, or press `w` to run the
web version. Android and iOS emulators can be launched with `npm run android`
and `npm run ios`.

## Features

- Add, search, and delete expenses by category.
- Review current-day, weekly, and monthly spending.
- Set weekly and monthly budgets and track progress.
- View spending summaries and a live PHP-to-USD exchange-rate reference.
- Save expenses, budgets, and quick-add shortcuts locally with AsyncStorage.
